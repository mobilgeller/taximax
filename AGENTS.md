# Közös projektutasítások

- A kanonikus repó `mobilgeller/taximax`, alapága `main`.
- A közös folyamatleírás forrása `mobilgeller/kozos-projektiranyitas`.
- Induláskor frissítsd az `origin` állapotát és ellenőrizd a nyitott pull requesteket.
- Egy feladat egy friss alapágból indított ág és egy Draft pull request.
- Minden commitot tölts fel; a helyi vagy beszélgetésben maradt változás nem tekinthető átadottnak.
- Kiadáskor rögzítsd a pontos commitot, ellenőrzést, visszaállítási pontot és változatlan taget.
- Korábbi auditot csak forrás- vagy külső konfigurációváltozás esetén ismételj.
